# Pulsar

Repositorio de prueba para verificar el flujo de `push` y `pull` con GitHub.

## Propósito

Este archivo existe solo para comprobar que:

- Los cambios locales se pueden subir al remoto (`git push`).
- Los cambios del remoto se pueden traer al equipo local (`git pull`).

## Prueba rápida

```bash
# Subir cambios
git add README.md
git commit -m "Agregar README de prueba"
git push origin main

# Traer cambios
git pull origin main
```
